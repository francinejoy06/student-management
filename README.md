# Student Management System

A simple web-based Student Management System developed using:
- Node.js
- Express.js
- EJS
- MySQL
- Git
- GitHub

## Features
- View students
- Add students
- Edit students
- Delete students
- Search students
- Form validation

## Installation
1. Clone the repository:
   git clone https://github.com/francinejoy06/student-management.git
2. Install dependencies:
   npm install
3. Start MySQL (XAMPP) and create the database student_management with the students table.
4. Create a .env file with your database settings:
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=
   DB_NAME=student_management
5. Run:
   node app.js
6. Open:
   http://localhost:3000
